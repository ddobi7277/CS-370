# CS 370: Pirate Intelligent Agent - Deep Q-Learning

Project OverviewIn this project, I developed a reinforcement learning algorithm to solve a pathfinding problem within a grid-based maze environment. The scenario involved training an autonomous "pirate" agent to navigate an 8x8 maze to find a treasure while avoiding obstacles and boundary penalties.Provided Code: I was supplied with the foundational environment and memory frameworks. This included TreasureMaze.py (which defined the environment matrix, state transitions, and scalar reward structure), GameExperience.py (which managed the experience replay buffer for storing episode transitions), and the build_model() function (which constructed the baseline Keras feedforward neural network architecture).Created Code: I independently authored the qtrain() algorithm. This required implementing the core Deep Q-Learning logic from scratch, which included writing the epoch training loop, managing the $\epsilon$-greedy exploration-exploitation decay, sampling mini-batches from the experience replay buffer to break serial correlations, updating the target network weights, and defining the early-stopping completion checks to ensure the agent converged on a 100% win rate across all available starting cells.

# Computer Science Connections

What do computer scientists do, and why does it matter?
Computer scientists design, analyze, and build algorithmic systems to solve complex, real-world problems. Whether developing quantitative financial models, securing autonomous networks, or training machine learning agents, the work fundamentally matters because it bridges the gap between theoretical mathematics and practical, scalable tools. By automating complex reasoning and optimizing vast datasets, computer scientists create infrastructure that drives innovation, efficiency, and safety across nearly every modern industry.

How do I approach a problem as a computer scientist?
I approach problems through systematic decomposition and algorithmic modeling. When confronted with a complex challenge, I break it down into its fundamental components by defining the environment (inputs/state space), the available operations (action space), and the ultimate objective (reward function). In this project, rather than hard-coding a static path to the treasure, I engineered a dynamic framework that allowed the agent to statistically optimize its own policy through continuous trial, error, and temporal difference learning.

What are my ethical responsibilities to the end user and the organization?
As a computer scientist, I have a strict responsibility to ensure that the systems I deploy are safe, transparent, and tightly aligned with human intentions. This involves proactively protecting user data privacy, mitigating algorithmic bias, and ensuring models do not exploit loopholes to achieve their goals. Because autonomous systems are highly susceptible to "reward hacking"—where an agent causes unintended damage while single-mindedly pursuing a metric—I am ethically obligated to implement robust sandbox constraints, strict access controls, and human-in-the-loop oversight to protect both the organization and the end users from catastrophic edge cases.
